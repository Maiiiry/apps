# Repository defaults

Use Go for services, Connect RPC and PostgreSQL for Delcore, and React/Rsbuild with the pinned Rust Tauri runtime for the application shells. Prefer UUID v7 for new persisted entities, structured logging, enum types, and AGPL-3.0-only for repository-owned code. Node.js 24 is selected by `.nvmrc`; Go and Rust versions are selected by `go.mod` and `rust-toolchain`.
